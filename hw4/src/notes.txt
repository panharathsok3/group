# How to Use

    #####
# Creating a new project

# To create a new project, run the new-project command
and give it the height and width of your choice.

For example if you want your project to have a
height of 5 and width of 10 you would:

Do: new-project 5 10
    new-project height width
    ######


   ######
# To load an existing project from anywhere on your computer into
the program, run the load-project command and pass in the file path.

For example if you want to load a project called myCollage
from your desktop into the program, you would :

Do: load-project desktop/myCollage
    load-project filePath
     ######


# After creating or loading your project, you can now add layers,
# images and transform them to your liking.

    ######
# To add a new layer to your project, run the add-layer command
and pass in a layer name of your choice.

For example if you want to create a new layer called 'designs' in
your existing project, you would:

Do: add-layer designs
    add-layer layerName
     ######


# Once your layer is created, you can then add Images to it.

     ######
# To add an image to your layer, run the add-image-to-layer command
and provide the name of the layer you want to place that image
on, as well as the location of the image on your device and
finally the position you want to place the image at.

For example, if you want to add an image from your desktop called
'image1' to a layer you created called 'designs' starting from the
top left corner of your project screen, you would

Do: add-image-to-layer designs desktop/image1 0 0
    add-image-to-layer layer-name image-path x-pos y-pos
     ######

 # Once your image is successfully on the layer, you
 can add some effects to it.


  ######
 #To transform any image on a layer,
  run the set-filter command and pass in
  the layer name of the layer which has the image you want
  to transform as well as any of the filter options
  which our program supports.

 For example, if you want to isolate the red-component of
 the image on the layer called 'designs' you would

 Do:set-filter designs red-component


 If you want to isolate the green-component of
  the image on the layer called 'designs' you would

 Do: set-filter designs green-component

 If you want to isolate the blue-component of
   the image on the layer called 'designs' you would

  Do: set-filter designs blue-component

  If you want to increase the brightness of
  the image on the layer called 'designs' by its
  value, you would

  Do: set-filter designs brighten-value


  If you want to increase the brightness of
  the image on the layer called 'designs' by its
  luma, you would

  Do: set-filter designs brighten-luma


  If you want to increase the brightness of
  the image on the layer called 'designs' by its
  intensity, you would

  Do: set-filter designs brighten-intensity


  If you want to reduce the brightness of
    the image on the layer called 'designs' by its
    value, you would

    Do: set-filter designs darken-value


    If you want to reduce the brightness of
    the image on the layer called 'designs' by its
    luma, you would

    Do: set-filter designs darken-luma

    If you want to reduce the brightness of
    the image on the layer called 'designs' by its
    intensity, you would

    Do: set-filter designs darken-intensity

 NOTE: These are the only filters our program supports currently.
 ######


+ After you apply any of the filters on you image(s),
you should save the image to make sure your work
does not get lost.

 ######
 To save an image after applying filters, run the save-image
 command and provide the location of where you want this
 new image to be stored.

 For example, to save a final image to the images folder,

 Do: save-image images/newImage.ppm
 ######


 ######
 To save a project, run the save-project command
 and pass in the path to store the image at.

Do: save-project projects/projectName.collage

 ######


 ######
 After all work has been done and saved, and you are
 ready to quit the program, run the quit command.

 Do: quit

 ######

  private boolean isPositionOccupied(String layerName, int row, int col) {
    if (row < this.canvasHeight || row > this.canvasHeight || col < this.canvasWidth || col > this.canvasWidth) {
      throw new IllegalArgumentException("The Row and column that you specified " +
              "are out of the bounds of this layer. Please Try again");
    }

    Pixel pixels = new Pixel(0, 0, 0);
    List<Integer> possibleCoordinates = new ArrayList<>();
    List<List<Integer>> occupiedPixels = new ArrayList<>();

    //get every position on a layer
    // check if they have an image(pixels)
    // return false if they do else return true

    for (int i = 0; i < this.canvasHeight; i++) {
      for (int j = 0; j < this.canvasWidth; j++) {
        possibleCoordinates.add(i, j);
      }
    }

    //These are pixels that are on the grid currently
    List<Integer> listOfPixels = new ArrayList<>() {{
      int r = possibleCoordinates.get(pixels.getRedComponent());
      int g = possibleCoordinates.get(pixels.getGreenComponent());
      int b = possibleCoordinates.get(pixels.getGreenComponent());
    }};

    occupiedPixels.add(listOfPixels);

    if ((occupiedPixels.contains(row) && (occupiedPixels.contains(col)))) {
      return true;
    }
    return false;
  }
